# Code of Conduct

fid adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in every fid space: issues, pull requests, discussions and
reviews, and wherever someone represents the project.

In short: be respectful and constructive. Harassment, personal attacks,
and publishing someone's private information are not acceptable.

## Reporting

Report a problem to the maintainer privately at
**justpraveenhere@protonmail.com**. Every report is reviewed, and the reporter's
privacy is respected.

The maintainer enforces this code using the Contributor Covenant's
enforcement guidelines: correction, warning, temporary ban, permanent ban.
