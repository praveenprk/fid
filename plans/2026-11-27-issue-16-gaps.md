## Notes for whoever picks up the next area

- Regenerate vectors.json with Python 3.12 on Linux, as CI does. On macOS,
  libm changes the last digits of about 15 existing floats. If you
  generate there, splice in only your new group: take the generated
  group, keep every other group from `main`, and dump with `indent=1,
  ensure_ascii=False` plus a trailing newline. CI's `git diff
  --exit-code conformance/` confirms the result.
- Run `python3 spec/traceability.py` to rewrite spec/TRACEABILITY.md.
- If fid already meets the rule, the pull request is `no-behaviour-change`.
  If the vectors fail first, the fix goes in the same pull request with a
  `Spec:` line.
